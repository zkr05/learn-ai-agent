# Stage 3 出口考核（从零写你的第一个 agent）

规则：**不参考模板/参考解答**，从零写 `stage3_exit.py`。可以翻自己的练习。
环境：Ollama + qwen2.5:3b，服务在跑。

---

## 任务 1：单步 ReAct agent（30 分）

**自己选一个工具**（不许用课程用过的 get_weather / lookup_fact / 温度转换 / 查人口）：
候选：查汇率 / 算 BMI / 查城市距离 / 翻译单词 / 自己发明。

要求（全部从零写）：
- 工具 schema（name / description / parameters / required / 该用 enum 就用）
- TOOL_IMPL（工具实现）
- react_loop（ReAct 循环）
- 一个问题，让模型调用你的工具并给出正确回答

## 任务 2：多步任务（30 分）

同一个 agent，跑一个**需要 2-3 次工具调用**的任务（可以组合 2 个工具，比如"查两个汇率再算差额"）。
要求：给出正确答案、max_iter 安全网。

## 任务 3：错误恢复（20 分）

故意让工具失败（问一个工具不认识/不支持的东西），展示：
- 模型读到错误 dict 后的反应
- 它怎么恢复（重试/改参数/告诉用户）

## 任务 4：概念问答（20 分，写进文件顶部注释）

1. Agent 的 3 个最小部件是什么？缺一个行不行？
2. 多步 ReAct 什么时候该停？
3. 为什么工具错误要 `return dict` 而不是 `raise`？
