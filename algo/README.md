# 算法练习

> 目的：实习笔试。**每天 1 题**，第 3 天和第 7 天各重写一遍。
> 起步阶段只做 Easy，从「数组」「哈希表」开始。

## 提交信息格式（很重要）

复盘 agent 只读提交信息的**第一行**，所以写具体：

```
刷题D01：数组-两数之和（看题解才会，暴力→哈希）
刷题D02：哈希-字母异位词分组（一次过）
复习D05：两数之和 独立重写成功
```

三段式：`刷题Dxx：分类-题名（状态/卡点）`

## 每天的流程

```
① 自己想 15 分钟（想不出很正常，别硬耗）
② 看题解，看懂为止
③ 【关键】关掉题解，自己从头写一遍 —— 写不出来就再看，直到能独立写出来
④ 填 notes.md（思路 / 卡点 / 下次注意）
⑤ 提交（用上面的格式）
```

**第 ③ 步不能省**，它就是"看懂"和"会写"之间的那道坎。
